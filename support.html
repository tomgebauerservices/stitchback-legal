Stitchback – Support

Stitchback is a Jira Cloud app that merges duplicate work items. Support is run by one person, by e-mail only.

How to reach support

E-mail: support@alpscreen.de

There is no phone, chat, or forum channel.

Response target

We aim to reply within 2 working days (Monday to Friday, German public holidays excluded). This is a target only. There is no guarantee of a reply time, of a fix date, or of availability. Support is asynchronous.

What to put in your e-mail

  • The URL of your Jira site (for example https://yourcompany.atlassian.net).
  • The work item keys involved (for example ABC-12 and ABC-15).
  • The time the problem happened, with time zone.
  • The exact text of the message the app showed, including the line “Reference for support: …” if the window shows one.

Please do not send customer content: no work item descriptions, comments, attachments, screenshots with personal data, or credentials. Work item keys, the time and the message text are enough for us to find the cause.

Emergency

If a merge behaves wrongly and you need to stop it:

  • If the app shows “Stitchback is paused” (the emergency stop), the app changes nothing in Jira while it is paused. A merge that was running stops after its current step; what was copied so far stays. Try again in a few hours and write to support@alpscreen.de if it stays off.
  • Undo of a merge and the export of the merge records keep working without a license. Use “Undo this merge” on the merged work item to restore it. A Jira administrator can export the merge records at any time with “Export all merge records” on the admin page “Stitchback – merge records” (Jira settings → Apps).
  • You can uninstall the app at any time. Atlassian then deletes the app data according to its storage lifecycle (Privacy Policy, Section A5). Export the merge records first if you want to keep them: the export is no longer available after uninstallation.
