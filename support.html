Stitchback – Support

Stitchback is a Jira Cloud app that merges duplicate issues. Support is run by one person, by e-mail only.

How to reach support

E-mail: support@alpscreen.de

There is no phone, chat, or forum channel.

Response target

We aim to reply within 2 working days (Monday to Friday, German public holidays excluded). This is a target only. There is no guarantee of a reply time, of a fix date, or of availability. Support is asynchronous.

What to put in your e-mail

  • The URL of your Jira site (for example https://yourcompany.atlassian.net).
  • The issue keys involved (for example ABC-12 and ABC-15).
  • The time the problem happened, with time zone.
  • The exact text of the message the app showed.

Please do not send customer content: no issue descriptions, comments, attachments, screenshots with personal data, or credentials. Issue keys, the time and the message text are enough for us to find the cause.

Emergency

If a merge behaves wrongly and you need to stop it:

  • If the app shows the notice that merging is paused (the emergency stop), the app does not change any issue. Try again in a few hours and write to support@alpscreen.de if it stays off.
  • Export of all app data and Undo of a merge keep working without a license. A Jira administrator can export all app data at any time on the Stitchback admin page. Use Undo on the merged issue to restore it.
  • You can uninstall the app at any time. Atlassian then deletes the app data according to its storage lifecycle (Privacy Policy, Section A5). Export the app data first if you want to keep it: the export is no longer available after uninstallation.

Security reports

Do not report security problems here. Send them to security@alpscreen.de.
